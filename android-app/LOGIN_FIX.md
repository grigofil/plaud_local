### **Как работает логин:**

#### **Диалог авторизации:**
- **Поля ввода** - имя пользователя и пароль
- **Валидация** - проверка на пустые поля
- **HTTP запрос** - отправка данных на сервер
- **Обработка ответа** - сохранение токена при успехе

#### **Управление сессией:**
- **Автоматическое сохранение** - токен и имя пользователя
- **Восстановление** - при запуске приложения
- **Выход** - очистка всех данных авторизации

### **Файлы, которые были изменены:**

1. **SettingsFragment.kt:**
   - Добавлены импорты для HTTP клиента
   - Реализован `showLoginDialog()` с полным функционалом
   - Добавлен `performLogin()` для HTTP запроса
   - Добавлен `logout()` для выхода из системы
   - Улучшен `updateAuthStatus()` для обновления UI

### **Как проверить:**

1. **Откройте раздел "Настройки"** в приложении
2. **Нажмите кнопку "Войти"** - должен появиться диалог
3. **Введите данные** - имя пользователя и пароль
4. **Нажмите "Войти"** - должен произойти запрос к серверу
5. **При успехе** - кнопка изменится на "Выйти"
6. **При ошибке** - появится сообщение об ошибке

### **Технические детали:**

- **HTTP клиент** - OkHttp для запросов к API
- **Формат данных** - MultipartBody для отправки формы
- **Обработка ошибок** - JSON парсинг ответов сервера
- **Сохранение** - SharedPreferences для токена и статуса
- **UI обновления** - runOnUiThread для безопасного обновления

### **API эндпоинт:**
```
POST {api_url}/auth/login
Content-Type: multipart/form-data

username: {username}
password: {password}
```

### **Ответ при успехе:**
```json
{
  "access_token": "jwt_token_here",
  "username": "username"
}
```

Теперь логин работает полностью! 🎉
