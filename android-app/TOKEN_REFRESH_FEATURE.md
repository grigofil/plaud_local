# 🔄 Система автопродления токена

## 📋 Обзор изменений

Добавлена система автоматического обновления JWT токенов для решения проблемы быстрого истечения сессий.

## 🔧 Технические изменения

### 1. API изменения (`api/main.py`)
- Добавлен endpoint `/auth/refresh` для обновления токенов
- Увеличен срок жизни токена с 30 минут до 24 часов (`ACCESS_TOKEN_EXPIRE_MINUTES = 1440`)

### 2. Android приложение
- Создан класс [`TokenManager.kt`](android-app/app/src/main/java/com/example/plaudlocal/TokenManager.kt) для управления токенами
- Обновлены все HTTP запросы для использования автоматического обновления токенов

## 🎯 Функциональность

### Автоматическое обновление токенов:
1. **При ошибке 401/403** → автоматическая попытка обновления токена
2. **При успешном обновлении** → повтор запроса с новым токеном
3. **При неудачном обновлении** → автоматический logout и уведомление пользователя

### Увеличенное время жизни:
- Токены теперь действительны **24 часа** вместо 30 минут
- Снижена частота необходимости повторной аутентификации

## 🔄 Workflow обновления токена

```
1. Пользовательский запрос с истекшим токеном
   ↓
2. Сервер возвращает ошибку 401/403
   ↓
3. TokenManager автоматически вызывает /auth/refresh
   ↓
4. При успехе: сохраняет новый токен и повторяет запрос
   ↓
5. При неудаче: автоматический logout и уведомление
```

## 📱 Интеграция с существующим функционалом

### Обновленные компоненты:
- **RecordingFragment** - загрузка файлов и проверка статуса
- **HistoryFragment** - загрузка истории и результатов
- **SettingsFragment** - управление аутентификацией

### Обработка ошибок:
- **Успешное обновление** → прозрачно для пользователя
- **Неудачное обновление** → понятное уведомление и автоматический logout

## 🛡️ Безопасность

- Endpoint `/auth/refresh` требует валидный токен для обновления
- Проверка соответствия username в токене и запросе
- Автоматическая очистка данных при неудачном обновлении

## 🚀 Готово к использованию

Все изменения протестированы и готовы к сборке. Система автоматически обрабатывает истечение токенов без вмешательства пользователя.
