# Обновление навигации приложения

## Что изменилось

Приложение теперь использует нижнюю навигацию с тремя основными разделами:

### 1. Запись (Recording)
- Запись аудио с микрофона
- Выбор файлов для загрузки
- Загрузка файлов на сервер
- Просмотр результатов обработки

### 2. История (History)
- Просмотр истории заданий
- Действия с заданиями (просмотр, скачивание, удаление)
- Загрузка истории с сервера

### 3. Настройки (Settings)
- Аутентификация (вход/выход)
- Настройка API URL
- Выбор темы (светлая/темная/авто)
- Выбор языка (русский/английский)
- Информация о приложении

## Новые файлы

### Layout файлы:
- `fragment_recording.xml` - интерфейс раздела записи
- `fragment_history.xml` - интерфейс раздела истории
- `fragment_settings.xml` - интерфейс раздела настроек
- `activity_main_new.xml` - новый главный layout с нижней навигацией

### Kotlin классы:
- `RecordingFragment.kt` - логика раздела записи
- `HistoryFragment.kt` - логика раздела истории
- `SettingsFragment.kt` - логика раздела настроек
- `MainActivityNew.kt` - новая главная активность

### Binding классы:
- `FragmentRecordingBinding.kt`
- `FragmentHistoryBinding.kt`
- `FragmentSettingsBinding.kt`

### Ресурсы:
- `bottom_navigation_menu.xml` - меню нижней навигации
- `ic_settings.xml` - иконка настроек

## Как использовать

1. Замените `activity_main.xml` на `activity_main_new.xml`
2. Замените `MainActivity.kt` на `MainActivityNew.kt`
3. Обновите `AndroidManifest.xml` для использования новой активности
4. Добавьте недостающие зависимости в `build.gradle`

## Преимущества новой структуры

- **Лучшая организация**: Каждый раздел имеет свой фрагмент
- **Удобная навигация**: Нижняя навигация позволяет быстро переключаться между разделами
- **Модульность**: Легко добавлять новые разделы или изменять существующие
- **Современный UI**: Соответствует Material Design 3
- **Лучшая производительность**: Фрагменты загружаются по требованию
